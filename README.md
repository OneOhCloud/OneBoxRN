# 欢迎使用你的 Expo 应用 👋

这是一个用 [`create-expo-app`](https://www.npmjs.com/package/create-expo-app) 创建的 [Expo](https://expo.dev) 项目。

## 开始使用

1. 安装依赖

   ```bash
   npm install
   ```

2. 启动应用

   ```bash
   npx expo start
   ```

在输出中，你会看到以下几种打开应用的方式：

- [开发构建（development build）](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android 模拟器](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS 模拟器](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)：一个用于体验 Expo 应用开发的受限沙箱

你可以通过编辑 **app** 目录下的文件开始开发。本项目使用[基于文件的路由（file-based routing）](https://docs.expo.dev/router/introduction)。
